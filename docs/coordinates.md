# Координаты и фильтр

- **S**: оси чипа MPU-6050; raw и все постоянные калибровки заданы здесь.
- **B**: корпус. По умолчанию S=B; `R_BS` — целочисленная знакоперестановочная
  ортогональная матрица с det=+1. Отражения запрещены. Строки в JSON/CSV row-major.
- **W**: локальная правосторонняя, Z вверх, X — начальный относительный курс,
  **не север**. Географического курса и абсолютного yaw нет.
- `q=(qw,qx,qy,qz)`, Гамильтон, `v_W=R(q)v_B`.
- `R=Rz(yaw)Ry(pitch)Rx(roll)`. Внутри рад, UI градусы. Состояние кватернионное
  даже у сингулярностей Эйлера.

При покое Z вверх удельная сила `[0,0,+g]`, не гравитационное ускорение `[0,0,-g]`.
Демонстрационное `a_W=R(q)f_B+[0,0,-g]` не превращает модуль в полноценную
инерциальную навигацию и не устраняет двойное интегрирование ошибок.

Порядок: **raw -> номинальные SI в S -> программная калибровка в S -> R_BS -> Mahony**.
Акселерометр LSB/g: 16384/8192/4096/2048; гироскоп LSB/(°/с):
131/65.5/32.8/16.4 для ±250/500/1000/2000. `rad/s = dps*pi/180`.
Температура MPU `raw/340+36.53 °C` обрабатывается отдельно.

## Ровно реализованная форма

```text
u = normalize(f_B)                    # только конечный ненулевой вектор
v = transpose(R(q)) * [0,0,1]
e = cross(u,v)
integral = clamp(integral + Ki*e*dt, -0.5, +0.5) # по компонентам, rad/s
omega_eff = omega_B_calibrated + Kp*e + integral
q_dot = 0.5 * q ⊗ [0,omega_eff]
q = normalize(q + dt*q_dot)           # явный Euler, старый q для всех компонент
```

Сначала обновляется integral, потом q. Нет twoKp/twoKi и скрытого множителя 2.
Стартовые **проектные**, не экспериментально подобранные Kp=2 с⁻¹, Ki=0 с⁻².
При Ki=0 integral немедленно нулевой. Bias вычитается ровно один раз; integral
не сохраняется автоматически в калибровку. Нет адаптации по динамике, ZUPT,
заморозки/обнуления yaw на покое или автоматического отбрасывания неудобных данных.
При нулевом/NaN акселерометре только коррекция пропускается с флагом; gyro может
продолжить интегрирование, если он конечен. Норма вне ±20% g0 и насыщение отмечаются;
норма около g не гарантирует отсутствия поступательного ускорения.

`dt` из последовательных DRDY t_us. Нулевой, отрицательный, >2,5 периода —
разрыв, потеря готовности и сброс динамического состояния. Функция одиночного
шага также запрещает dt>0,05 с. Большой dt **не заменяется** 0,01 с.
После потерь/ресинхронизации ориентация вновь требует подтверждения покоя.

## Инициализация

Подтверждение покоя: 1 с подряд, `|omega_B|<0.08 rad/s`, норма в ±20% g0,
дисперсия каждого f_B <=0.01 (м/с²)². Затем roll/pitch из среднего f, yaw=0 условно.
Это инженерные критерии, не гарантия неподвижности и **не калибровка bias**.
В движении raw доступен; ORIENTATION_INVALID остаётся до подтверждения.
При большой некалиброванной скорости смещения готовность может не наступить:
сначала отдельно выполните gyro master.

`reset_orientation` явный, вне опыта. `zero_yaw` вне опыта использует
`q_new=qz(-yaw)⊗q`, то есть согласованное вращение мировой системы вокруг Z;
не зануляет произвольную компоненту q. Интегральная коррекция живёт в B.

q в записи относится к состоянию **после** соответствующей выборки. Начальное
состояние до `before_seq` содержит q, integral, предыдущий t_us, ready и статистику
инициализации. Потеря любой исходной выборки или исходной границы исключает
обещание точного replay. q и -q — одна ориентация: сравнивать
`min(norm(q1-q2),norm(q1+q2))`. C float32 против Octave float64 fixture проверяется
с допуском 2e-5 по этой норме за 1500 шагов/15 с, integral 1e-5 rad/s.
Это допуск реализации, не паспортная/измеренная точность MPU.
