# Учебная обработка

Здесь можно разместить свои интегратор гироскопа и скалярный комплементарный
фильтр. Они не являются обязательными параллельными фильтрами прошивки.
Используйте `run.omega_B`, `run.f_B`, время **ESP32** и `run.segments`;
начинайте новый участок при разрыве. Не интерполируйте потери и не объявляйте
траекторию Comau эталоном без независимой измеренной телеметрии.

`reference/` — преподавательская проверка соглашений, не готовое решение всех
учебных заданий. Условия сравнения начального состояния обязательны.
